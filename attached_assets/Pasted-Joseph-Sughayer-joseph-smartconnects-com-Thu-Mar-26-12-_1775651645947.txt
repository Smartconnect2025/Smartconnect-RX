MEETING RECAP (Monday March 24th with Mitch Archer)

The meeting covered how PioneerRx's API works, how we connect to it, and what the costs look like. Here are the key takeaways:

1. How the Connection Works:

PioneerRx's production API is PRIVATE — it runs inside each pharmacy's local network
To connect in production, we need either:
A site-to-site VPN from our server to the pharmacy's network, OR
An on-premises component (a small app running on a workstation inside the pharmacy)
PioneerRx does NOT allow installations on their servers — it must run on pharmacy hardware
This is for HIPAA compliance and security
2. Credentials & Access:

Each pharmacy gets its own API key and shared secret
Since we're acting as the pharmacy's programming staff (not a multi-pharmacy vendor), each pharmacy is responsible for its own credentials and fees
Sandbox/test access does NOT require contracts or NDA
Production/store access DOES require signed contracts
3. Costs (deferred for now, but FYI):

Base fee: $40 per pharmacy location per month
Per-prescription fee: approximately $0.13 or less (not finalized)
Vendor minimum: $2,000/month (applies if we switch to vendor model later)
Pharmacies pay their own transaction fees — SmartConnect does not pay these
4. Technical Details:

Each prescription item requires a separate API call (3 medications = 3 calls)
Must search for existing patients before adding new ones (to avoid duplicates)
Real-time prescription tracking (RX Events/webhooks) is available but only if the pharmacy uses Pioneer's shipping integration
No API exists to sync compounding medication inventory back into PioneerRx — pharmacy staff must create new items manually
WHAT WE'VE BUILT

Our system is fully integrated with PioneerRx's Enterprise API. Here's what works:

Submit prescriptions into PioneerRx (uses their RxAddOnHold method)
Automatically searches for patients and prescribers in PioneerRx before submitting (required by their system)
Check prescription status in real-time
Receive automatic status updates via webhook when a prescription is filled, verified, completed, etc.
Search patients, prescribers, and medications in PioneerRx
Check refill eligibility
Test the API connection from the admin panel
Each pharmacy stores its own PioneerRx credentials securely (encrypted in our database)
